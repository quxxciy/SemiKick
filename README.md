# SemiKick

---

A simple mod that adds a kick mechanic to the game, along with the ability to upgrade it.

## Features and mechanics:

- **Kick**: Lets you kick any object. Bound to F by default; can be changed in the settings.
- **Kick upgrade**: Increases the power of the kick.

## Installation:
**Dependencies**: BepInExPack, RepoLib, KeybindLib
### Automatic:

Install the mod into your modpack via the Thunderstore/r2modman mod manager.

### Manual:

1. Make sure you have **BepInEx** installed
2. Place the "SemiKick.dll" file into the "BepInEx/plugins/" folder
